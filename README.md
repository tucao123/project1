# RFR · 关系摩擦预演器 MVP

依据 `毕设prd.md`、`RFR_心理学文献支撑与学术指导.md`、`元现代风格.md` 实现的前端演示。

## 启动

```bash
npm install
npm run dev        # http://localhost:5173/
```

`npm run build` 检查并构建；`npm run preview` 预览（4173）。改 `.env` 后要重启服务。

## 结构

| 路径 | 作用 |
|---|---|
| `.env` / `.env.example` | 所有配置，由 `src/config/env.ts` 读取 |
| `src/styles/metamodern.css` | 原风格样式 + 同风格扩展 |
| `src/components/` | 按钮、动效、图表、翻页、账户面板 |
| `src/domain/` | 12 个场景、结果计算、陪练内容、安全检查 |
| `src/state/RfrContext.tsx` | 全局状态 |
| `src/views/` | 六个页面 |

技术：Vite + React + TypeScript，纯前端演示，状态只存内存，刷新会重置。

## 页面

| 页面 | 做什么 |
|---|---|
| 观察 | 说说情况、确认年龄 |
| 预演 | 3 个场景，每题选一个最可能的做法 |
| 画像 | 看结果，并能对上每一次选择 |
| 陪练 | 一句话怎么说、对方没接住怎么办 |
| 档案 | 以前的练习和这几周的变化 |
| 群体 | 只看整体的数据看板 |

右上角「账户」按钮拉出抽屉，登录、付费、设置、账户管理（导出、删除）都在里面。陪练页「去解锁」、档案页「管理」可直接跳到对应分页。

## 配置

所有能改的都在 `.env`，包括文案、功能开关、价格、场景数量、安全规则、图片地址和账户面板。

- 有一条不能改：授权开关默认必须关闭（`VITE_FEEDBACK_CONSENT_DEFAULT` 设成 `true` 也会被改回 `false`）。
- 颜色、字体、圆角、动画写在 CSS 里，不开放配置，避免风格变样。
- `VITE_USE_MOCK=false` 会把记录发到 5 个接口；`VITE_ENABLE_QUICK_PANEL=false` 可关掉账户按钮。

## 边界

- 结果只描述刚才的选择，不判断性格，也不预测关系。
- 登录和付费都是演示，数据不保存，没有接入大模型。
- 热线和法规信息按源文档配置，请自行核实现行有效性。
